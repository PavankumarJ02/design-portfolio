# ◈ Design Philosophy

The portfolio is designed around three principles:

```text
┌──────────────────────────────────────────┐
│                                          │
│       VISUAL EXPERIENCE                  │
│              ↓                           │
│       TECHNICAL DEPTH                    │
│              ↓                           │
│       PERSONAL IDENTITY                  │
```

### 01 — Visual

Create an interface that immediately communicates personality, creativity, and technical ability.

### 02 — Technical

Present projects through real technologies, architectures, implementations, and engineering decisions.

Move beyond a traditional resume and show the person, interests, learning journey, and work behind the code.

# ◈ Getting Started

## Prerequisites

Make sure you have installed:

* **Node.js 18+**
* **npm / yarn / pnpm / bun**
* **Git**

Check your versions:

```bash
node --version
npm --version
git --version
```

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-portfolio.git
```

Move into the project:

```bash
cd your-portfolio
```

Install dependencies:

```bash
npm install
```

---

## Development

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

The application automatically updates when files are modified.
